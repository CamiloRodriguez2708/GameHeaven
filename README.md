## 🧠 Descripción

GameHeaven es una aplicación que simula una tienda de videojuegos donde los usuarios pueden explorar, guardar y gestionar juegos dentro de una biblioteca personal.

El proyecto está orientado al aprendizaje de:
- Interfaces gráficas en Java
- Manejo de eventos
- Organización de proyectos en NetBeans
- Uso de recursos multimedia
